# 资格审查与赋分试算程序

最新入口：双击 `启动桌面界面.cmd`。每岗位一份汇总Excel，每名考生另有独立赋分Excel；学籍报告优先、毕业证备用，成绩材料只检查照片存在，不运行OCR。显示建议得分和核验状态，模型参数隐藏并使用内部默认值。详见 [桌面版使用说明](桌面版使用说明.md)。明确资格不符合者不赋分；境外认证截止日固定为2027-07-31。

新增凭证试运行入口：`evidence_pipeline.py`，详见 [凭证核验使用说明](凭证核验使用说明.md)。该入口可选运行本地OCR和内网模型；下文原有 `review.py` 的填报试算流程继续独立运行。成绩栏明确填“是”现按用户确认口径0分并跳过成绩凭证，填“否”的正向分仍须材料支持。

双击本目录的 `一键运行.cmd` 即可处理配置中的人员Excel。所有处理均在本机完成，不调用Qwen或OCR，不安装或下载依赖。每次生成独立时间目录，源文件保持原样。

## 运行

在本目录打开PowerShell：

```powershell
& 'D:\3-anaconda\envs\py312\python.exe' '.\review.py'
```

处理下一批、表头相同的报名数据：

```powershell
& 'D:\3-anaconda\envs\py312\python.exe' '.\review.py' --input 'D:\数据\新报名表.xlsx'
```

工作表名称、岗位计划路径、截止日、招聘届别和原始填报快照日期在 `config.json` 中修改。默认相对路径以项目父目录为基准。当前配置截止日为 **2026-10-31**，毕业范围 **2025-01-01至2027-07-31**，届别2027。

程序依赖现有环境中的 `openpyxl`、`xlrd`。重建国内院校CSV另需现有 `lxml`。当前环境已经具备，无须安装。换电脑缺包时由使用者手动安装。

## 输出及业务复核

每次运行生成：

1. **资格审查与赋分试算.xlsx**：人员汇总、逐项依据、复核录入和操作说明。每人可按姓名或人员编号筛选查看全部30项。姓名不是关联主键。
2. **核验规则_业务审核.xlsx**：资格条件、取值列、评分处理逻辑、当前两份标准原文，以及业务审核意见/审核人空白列。
3. **院校层次与QS2027前200中英文.xlsx**：国内本科及以上院校、QS中英文和计分档次、专科备查、来源说明。
4. 人员汇总CSV和运行记录JSON：便于复用与追溯。

“已识别试算小计”是已有明确依据的分数之和。待复核项目可能已有部分证据分，最终得分须在补充后确定。**待复核项不是按0分定案；小计不用于最终排名。** 资格不符合人员仍保留诊断性试算。

### 专业匹配（v2）

规则工作簿新增“各岗位专业清单”和“专业匹配规则”；结果工作簿新增“专业匹配明细”。原始名称、规范化名称、候选专业、匹配类型及判断依据均单独列出。

- 完整名称精确相同，或完整要求名称后附普通方向/代码括号，明确符合。全半角括号、英文大小写、空白和不可见字符先统一。
- “网络工程专业→网络工程”“会计专业硕士→会计”，以及包含关系或至少两个相同前缀字，列为疑似相关、待复核。不会删除“学”“工程”等字后自动放行，也不自动认定专业大类包含其所有细分专业。
- “法律（法学）”与“法律（非法学）”是独立名称。岗位明确列出哪一项，才按该项精确命中。限定冲突且无其他候选时不符合；岗位只写“法律”而填报带法学/非法学限定时待复核，不由删除括号扩大范围。
- 当前三个法律类岗位同时列出“法律”“法律（法学）”“法律（非法学）”，两种限定名称均能精确命中。
- 中英文括号和标点可统一；英文专业名、英文缩写与中文名之间的语义对应需人工核对。岗位和填报均使用同一个英文名称时可直接精确匹配。
- 岗位清单仅按括号外的逗号、顿号、分号拆分；括号内标点保留。逗号分隔清单中的真实换行、字面量 `\n` 当作排版断行清除。只有换行而无分隔标点的清单不能可靠区分断行与多专业，列为待复核。
- Q10以AA主专业为准。Q13对AG经历专业与AA采用同一套名称比较规则，疑似修饰词差异单独提示；学校或毕业年月差异仍独立保留。

专业规则版本和程序摘要加入运行记录及复核输入指纹，规则改变后旧人工复核表需重新确认。专业名称候选仅用于提示业务审核，最终通过仍需复核依据。

下列内容需要业务部门补充：普通高校及非委培非定向声明、未落实工作单位、学历学位取得及境外认证、无法从填报文字准确认定的科研/证书/职务/奖项。人岗匹配度按参考赋分表口径以本人填报性别直接定分（管理岗男3女0、业务岗男5女0），仅在性别空白时交人工确认。当前按填报文字预审，材料真实性核验由后续项目完成。

填好结果表的“复核录入”Sheet：

- 资格项目填写“复核结论”。
- 评分项目填写“复核得分”，取本项目允许的分值档位。
- 每条填写“复核依据”和“复核人”，奖项/证书/实习等写明日期及学历阶段。
- 保存为新的Excel文件，然后重跑：

```powershell
& 'D:\3-anaconda\envs\py312\python.exe' '.\review.py' --review 'D:\数据\业务已复核.xlsx'
```

原始人员文件、岗位表、配置、院校字典发生变化后，旧复核记录会失效，程序提示重新复核，避免把旧判断套到新数据上。空白录入行自动忽略。重复复核键、非法分值和无依据的决定会报错。

## 院校字典口径

- 教育部2026-06-17普通高校名录：2952所，含1412所本科和1540所专科；另补双一流中的3所军队高校。
- 计分优先级：985、211、其他双一流、其他公办、民办及独立学院。三个工程标记独立保留，计分层次互斥。
- 985共39所；211历史原表112个名称，按地矿油两地现行学校实体展开后115所（含985）。此处采用学校实体口径，不把华北电力两个办学校区算作两所独立高校。
- 第二轮双一流147所。上海体育学院等已核实更名用明确映射。科研院所、党校、合作办学和未知旧名需补充依据。
- QS采用截至2026-10-26官网展示的**2027主榜前200名**。英文名称与原始名次来自官网；中文为整理译名，须结合英文与国家地区核对，不标称QS官方中文版本。已统一香港城市大学、谢菲尔德大学、海德堡大学的城市国家地区格式，并采用“Al-Farabi Kazakh National University／阿里-法拉比哈萨克国立大学”。
- QS按公布名次数值分档，保留“=”并列符号。源页面97–100和115–118附近序号存在衔接异常，已在字典说明记录；本次相关异常在同一赋分档内。没有擅自修改官方显示值。
- QS未命中返回待核验。程序不会把未知校名自动归为200名以后，也不会把独立学院按母校识别。
- 以学校为单位的双一流层次不代表其所有专业均为双一流学科。本次标准按院校层次计分，专业资格仍独立核验。

名单快照及官网原始文件保存在 `data/` 与 `data/raw/`。程序默认离线重用该快照，保证同批次结果可复现。以后更新排名，应先审核替换字典，不能把新旧版本混用。

重建国内字典（使用本次缓存原始文件）：

```powershell
& 'D:\3-anaconda\envs\py312\python.exe' '.\build_school_dictionary.py'
```

主脚本不自动修改业务标准。两份标准文件的哈希在配置中固定；标准文件更换后会停止运行，需审核新规则、修改对应程序和配置后再使用。
